# Wörterbuch

Dizionario tedesco ↔ italiano installabile sulla schermata home (PWA).

- Significati, traduzioni italiane per significato, esempi, combinazioni tipiche, forme e pronuncia da [de.wiktionary.org](https://de.wiktionary.org) (CC BY-SA 4.0)
- Traduzione rapida da [MyMemory](https://mymemory.translated.net)
- Ricerca inversa IT → DE, preferiti, cronologia, uso offline delle parole già cercate

App: https://gianlucasabbini-dot.github.io/woerterbuch/

Test del parser: `node tests/wikitext.test.mjs`
